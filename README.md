## 🚀 Meus trabalhos

### 🏙️ [Denúncias Urbanas](https://github.com/franciscojuniorfeitosabarros-ops/Denuncias-urbanas-) · *Fullstack*
Sistema web para a população registrar problemas urbanos, de forma **anônima ou identificada**.
- Mapa interativo com **Leaflet + OpenStreetMap** para marcar o local da denúncia
- **Protocolo único (UUID)** para acompanhar o andamento
- Histórico público com status (aberta, em análise ou resolvida)
- Cadastro, login e área "Minhas denúncias"
- Painel administrativo para a gestão dos status

`Python` `Django` `HTML` `CSS` `JavaScript` `Leaflet` `SQLite`

### 🎓 [Edutruancy](https://github.com/franciscojuniorfeitosabarros-ops/Edutruancy) · *Fullstack*
Plataforma web para **relatos anônimos no ambiente escolar**.
- Autenticação com cadastro e login via **NextAuth**
- Interface moderna e responsiva com **Tailwind CSS** e **shadcn/ui**
- Arquitetura com o App Router do **Next.js**

`TypeScript` `React` `Next.js` `NextAuth` `Tailwind CSS`

### 🚗 [Detector de Placas](https://github.com/franciscojuniorfeitosabarros-ops/Detector-de-Placas) · *Visão computacional*
Detecção de veículos e **leitura automática de placas em tempo real** pela câmera (ANPR).
- Detecção de carros, motos, ônibus e caminhões com **YOLOv8**
- Leitura dos caracteres da placa com **EasyOCR** (português e inglês)
- Processamento de imagem com **OpenCV**
- Projeto desenvolvido em equipe

`Python` `YOLOv8` `PyTorch` `OpenCV` `EasyOCR`

### 🏥 [Squad EPSILON](https://github.com/franciscojuniorfeitosabarros-ops/Squad-EPSILON) · *Back-end e estruturas de dados*
Conjunto de sistemas para a **área da saúde**, desenvolvidos em squad.
- **Prontuário eletrônico** com lista encadeada de consultas
- **Fila de emergência** e triagem de pacientes
- **Gestão de leitos** hospitalares
- **Controle de energia**
- **Visualizador de ressonância magnética**, com fila de triagem e pilha de cirurgias

`JavaScript` `Node.js` `Estruturas de Dados` `POO`

### 🤝 [Sistema de Gestão de ONG](https://github.com/franciscojuniorfeitosabarros-ops/3-Avalia-o-POO-UNICET--) · *Back-end*
Sistema para a gestão de uma ONG aplicando **Programação Orientada a Objetos**.
- Cadastro de **doadores, voluntários e membros**
- Gestão de **projetos sociais**
- Uso de herança, encapsulamento e polimorfismo

`Java` `POO`
